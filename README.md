# Расписание юрфака МГУ → ICS

Скрипт забирает расписание с [cacs.law.msu.ru](https://cacs.law.msu.ru/time-table/group?type=0), парсит таблицу и обновляет `schedule.ics` на GitHub. На этот файл можно подписаться в Google Calendar, Apple Calendar и других клиентах.

## Настройки

Отредактируйте `settings.json`:

```json
{
  "faculty": "Бакалавриат (основное отделение)",
  "course": "3",
  "group": "101"
}
```

Доступные отделения:

- `Бакалавриат (основное отделение)`
- `Бакалавриат (международно-правовой профиль)`
- `Магистратура`
- `Спецотделение "Второе высшее образование"`
- `Межфакультетские курсы юридического факультета`
- `Подготовительные курсы`

## Формат событий

- **Название:** `аудитория, предмет` — например, `412Б, ИнфТех [Лк]`
- **Описание:** имя преподавателя

## Логика обновления

При каждом запуске скрипт:

1. Создаёт события за **1 неделю назад** и **2 недели вперёд** от текущей даты
2. Удаляет из ICS события старше **2 месяцев**
3. Обновляет события в текущем окне, не трогая более старые и более новые записи
4. При смене отделения, курса или группы в `settings.json` **полностью очищает** старый ICS, чтобы не было накладок

## Локальный запуск

```bash
pip install -r requirements.txt
python sync_timetable.py --no-upload
```

## GitHub Actions

Workflow `.github/workflows/sync-timetable.yml` запускается каждый день в 08:00 МСК и вручную через **Actions → Sync timetable → Run workflow**.

После первого успешного запуска подпишитесь на календарь по ссылке:

```
https://raw.githubusercontent.com/<owner>/<repo>/<branch>/schedule.ics
```

## Переменные окружения

Для GitHub Actions дополнительные переменные не нужны — workflow сам коммитит `schedule.ics`.
